Why Torgy

Simple where it counts.

✓

Tasks, calendar & student workflows in one workspace

A weekly calendar that keeps schedule (when you work) separate from due dates (when it's due), with recurrence and priorities built in.

✓

Coordinator & student modes

One shared workspace with a coordinator MASTER overview and single-student filtering. Student mode hides coordinator-only views.

✓

Works with the tools you already use

Two-way Outlook calendar sync and Canvas assignment import — the only connections that ever leave your machine, and only if you enable them.

✓

Your data never leaves your computer

No accounts, no cloud, no telemetry. Local state is encrypted with Windows DPAPI, and everything core works fully offline.
