Features

Everything a coordinator needs.
Nothing phoning home.

Tasks & calendar, separated right

Weekly calendar with a clean split between schedule (when you work) and due dates (when it's due). Recurrence, priorities, and completion status built in.

Coordinator & student modes

One shared workspace with a coordinator MASTER view and single-student filtering. Student mode runs the same app with coordinator-only views hidden.

Info Dump with speech capture

Capture thoughts fast with local Windows speech capture, then review and file them. AI-inferred dates are always suggestions — they never become authoritative on their own.

Two-way Outlook sync

Sync your calendar with Microsoft Outlook via Entra OAuth. Outlook changes schedule work time only — your academic due dates are never rewritten.

Canvas assignment import

Pull assignments straight from Canvas with official due_at dates preserved, plus possible-date detection from titles, modules, and syllabus text.

Encrypted coordinator sync

Student/coordinator sync uses encrypted envelopes — X25519 key agreement with ChaCha20-Poly1305 authenticated encryption — and one-time pairing codes.

Protected local state

Your data is encrypted with Windows DPAPI for the current user. Offline queues, versioning, deterministic duplicate detection, and human review for the ambiguous cases.

Backup & restore

Export a full backup and restore or migrate with schema validation. A built-in readiness check verifies storage, sync, Outlook, and backup health.

Architecture

Local-first isn't a setting.
It's the architecture.

Torgy is a Tauri + React desktop app. There is no Torgy server, no hosted database, no analytics pipeline. The whole system fits inside one box:

Torgy.exe — on your PC

  • Bundled React UI
  • Rust local backend
  • DPAPI-protected local state
  • Local Windows speech capture
  • Local offline sync queue
  • Local encrypted sync identity

The only things that ever leave your machine

Outbound connections happen only to services you explicitly approve:

  • Microsoft Copilot (isolated bridge — never reads cookies, tokens, or passwords)
  • Microsoft Outlook / Graph (calendar sync)
  • Canvas (assignment import, if you enable it)

Nothing else. No telemetry, no tracking, no "anonymous usage stats."

FAQ

Questions, answered.

Is Torgy really free?

Yes. Torgy is a free download with no accounts, no subscriptions, and no paywalled features. It's a local tool, built to be useful — not to harvest users.

Where does my data go?

Nowhere. It stays on your computer, protected by Windows DPAPI encryption tied to your user account. There is no Torgy cloud to send it to.

Does it work offline?

Yes. Everything core — tasks, calendar, Info Dump, backups — works fully offline. Only the integrations you explicitly enable (Outlook, Canvas, Copilot) use the network.

Who is Torgy for?

Academic support coordinators managing many students, and students who want their tasks, dates, and calendar in one calm place. Coordinator mode gives the MASTER overview; student mode keeps it personal.

What is the Machine Agent?

An optional companion for coordinator/student sync setups. It runs as a system service, owns the protected sync spool, and exchanges only encrypted packets with the desktop app — student machines never get staff credentials.

How do I get updates?

New versions are published on the GitHub releases page. Download the latest installer and run it — your local data and settings carry over.
